Artwork files we can engrave from

Vector files give the cleanest result and the fastest setup. Raster artwork is fine too as long as it is high resolution — 300 dpi at the size it will be engraved.

  • Vector preferred — AI, EPS, PDF or CDR with outlines kept as paths, so lines stay sharp at any depth.
  • JPG and PNG accepted — at 300 dpi or better, supplied at the finished size rather than upscaled.
  • Send the artwork at final size, including any text you want set, so we can judge depth and placement before tooling the job.
  • Colour is not part of the file — we engrave the surface or the subsurface, and you choose the final tone separately.

Depth, placement and setup

Engraving is either surface, where the mark sits on the polished face, or 3D subsurface, where the laser writes inside the block so the image floats in the material. Depth is set per product: a heavy base accepts a deeper cut and a stronger outline, while a thin wall needs a shallow pass or it reads as a crack under light.

The engraving setup is part of the same production step as the body, so there is no separate tooling charge for standard engraving, and mixed multi-line texts — logo, name and dedication on separate lines — are priced as one job.

Size limits follow the product, not the machine: send the piece dimensions with your request and we will tell you the largest area we can reach and the minimum legible type size for that surface.

Engraving questions

Can you work from a JPG rather than a vector file?
Yes. Vector is preferred because the outline stays clean, but a JPG or PNG at 300 dpi at final size engraves perfectly well. Send it at the size it will be used and tell us if you can supply a vector version later.
Is there a setup or tooling charge for engraving?
No. Standard engraving and 3D subsurface work run on the same line as the body, so there is no separate tooling fee for the engraving itself.
How deep can you engrave, and how large can the text be?
It depends on the piece. Depth is chosen from the wall thickness and base weight so the mark holds without stressing the glass, and the maximum engraved area follows the dimensions you send us. We confirm both in the quotation.
